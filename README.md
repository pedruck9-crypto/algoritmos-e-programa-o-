# Ciclo 1 — CRUD introdutória no terminal

Esta versão pratica variáveis, operadores, condicionais e laços de repetição, conforme o escopo do primeiro ciclo da disciplina.

## Funcionalidades

- Menu interativo no terminal.
- Cadastrar, consultar, atualizar e excluir uma mídia.
- Validação simples das opções do menu com condicionais e repetição do menu com while.

Para manter o programa nas estruturas permitidas neste ciclo, esta etapa guarda um único registro em variáveis simples. A limitação é intencional; o suporte a vários registros será introduzido no Ciclo 2 com uma estrutura dinâmica.

## Tecnologias

Python e terminal. O programa usa apenas recursos básicos da linguagem, sem classes, funções próprias, coleções, bibliotecas externas, API ou banco de dados.

## Executar

    python crud_filmes_e_series.py

## Evolução

Este é o ponto de partida didático. A branch seguinte substitui as variáveis isoladas por uma coleção dinâmica. A aplicação web ampliada permanece na branch main.
