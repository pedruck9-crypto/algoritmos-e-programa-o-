# Ciclo 2 — CRUD com estruturas dinâmicas

Esta versão refatora a solução do Ciclo 1 e usa uma lista de dicionários para armazenar várias mídias em memória.

## Funcionalidades

- Menu interativo no terminal.
- Cadastrar, listar, buscar, atualizar e excluir mídias.
- Percorrer e alterar os registros com laços e condicionais.
- Atribuir um identificador sequencial a cada mídia.

## Conceitos praticados

Variáveis, operadores, condicionais, laços, listas e dicionários. As operações permanecem no fluxo principal do programa; a organização em funções próprias é o foco do Ciclo 3.

## Tecnologias

Python e terminal, sem dependências externas, API web ou persistência em banco. Os dados existem apenas enquanto o programa está em execução.

## Executar

    python crud_filmes_e_series.py

## Evolução

Esta etapa amplia a quantidade de registros que podem ser gerenciados. A branch seguinte mantém a estrutura dinâmica e organiza as operações em funções. A aplicação web ampliada permanece na branch main.
