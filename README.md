# Ciclo 3 — Aplicação final organizada em funções

Esta versão final didática mantém a lista de dicionários introduzida no Ciclo 2 e organiza as operações da CRUD em funções.

## Funcionalidades

- Menu interativo no terminal.
- Cadastrar, listar, buscar, atualizar e excluir mídias.
- Identificadores sequenciais e armazenamento em memória.
- Funções separadas para as operações e para o fluxo principal do menu.

## Conceitos praticados

Variáveis, operadores, condicionais, laços, listas, dicionários, parâmetros, retorno de valores e decomposição do programa em funções.

## Tecnologias

Python e terminal, sem dependências externas, API web ou persistência em banco. Os dados existem apenas enquanto o programa está em execução.

## Executar

    python crud_filmes_e_series.py

## Versão ampliada

A CRUD com interface web, API e persistência é uma versão de portfólio separada, preservada na branch main. Esta branch mostra a aplicação final dentro do escopo didático descrito para o Ciclo 3.
